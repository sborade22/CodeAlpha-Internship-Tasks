Task 3 – Secure Coding Review

Project Overview

This project was developed as part of my CodeAlpha Cybersecurity Internship.

The project demonstrates a simple Python-based login system with basic secure coding practices.

Features

- Username and password authentication
- Password input hidden in the terminal
- Password hashing using SHA-256
- Login success and invalid login messages
- Secure comparison of entered credentials

Technologies Used

- Python 3
- hashlib
- hmac
- getpass

Demo Login Credentials

- Username: admin
- Password: admin123

How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Run the following command:

"python secure_login.py"

4. Enter the demo username and password.

Learning Outcomes

- Understanding authentication systems
- Learning basic password hashing
- Understanding secure coding practices
- Handling invalid login attempts
